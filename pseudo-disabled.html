:disabled

Псевдокласс :disabled применяется к элементам формы, которые отключены и не доступны для взаимодействия пользователя (имеют атрибут disabled).

Синтаксис

селектор:disabled { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:disabled</title>
    <style>
        input:disabled {
            background-color: #ddd;
            color: #999;
            cursor: not-allowed;
        }
        button:disabled {
            opacity: 0.4;
        }
    </style>
</head>
<body>
    <input type="text" value="Активное поле"><br><br>
    <input type="text" value="Недоступное поле" disabled><br><br>
    <button disabled>Недоступная кнопка</button>
</body>
</html>
