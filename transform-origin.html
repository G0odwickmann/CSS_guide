transform-origin

Задаёт точку, относительно которой применяется преобразование transform. По умолчанию это центр элемента.

Синтаксис

transform-origin: x-offset y-offset [z-offset] | inherit

Значения

x-offset — горизонтальное положение точки (left, center, right, %, px).
y-offset — вертикальное положение (top, center, bottom, %, px).
z-offset — глубина для 3D-преобразований.
По умолчанию: 50% 50% (центр).

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>transform-origin</title>
<style>
.box {
    width: 80px; height: 80px;
    background: #9b59b6;
    display: inline-block;
    margin: 40px;
    color: white;
    text-align: center;
    line-height: 80px;
    transform: rotate(30deg);
}
.top-left {
    transform-origin: top left;
    transform: rotate(30deg);
}
.bottom-right {
    transform-origin: bottom right;
    transform: rotate(30deg);
}
</style>
</head>
<body>
<div class="box top-left">top left</div>
<div class="box bottom-right">btm right</div>
</body>
</html>
