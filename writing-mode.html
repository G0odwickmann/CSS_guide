writing-mode

Определяет направление текста: горизонтальное или вертикальное. Используется для поддержки языков с вертикальной письменностью, а также для декоративных эффектов.

Синтаксис

writing-mode: horizontal-tb | vertical-rl | vertical-lr | inherit

Значения

horizontal-tb — горизонтальный текст сверху вниз (по умолчанию).
vertical-rl — вертикальный текст справа налево.
vertical-lr — вертикальный текст слева направо.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>writing-mode</title>
<style>
.horizontal { writing-mode: horizontal-tb; background: #e8f4f8; padding: 10px; display: inline-block; margin: 10px; }
.vertical   { writing-mode: vertical-rl;   background: #e8f8e8; padding: 10px; display: inline-block; margin: 10px; height: 100px; }
</style>
</head>
<body>
<div class="horizontal">Горизонтальный текст</div>
<div class="vertical">Вертикальный текст</div>
</body>
</html>
