caption-side

Определяет положение заголовка таблицы, который задается с помощью тега caption. По умолчанию заголовок располагается перед таблицей, но его можно размещать и после нее.

Синтаксис

caption-side: top | bottom | inherit
top
Заголовок располагается сверху таблицы.

bottom
Заголовок отображается внизу таблицы.

inherit
Наследует значение родителя.

Пример:

<!DOCTYPE html>
<html>

<head>

    <meta charset="utf-8">

    <title>caption-side</title>

    <style>

        table {
            width: 100%;
            border: 1px solid #399;
        }

        caption {
            caption-side: bottom;
            padding: 10px;
            font-weight: bold;
        }

        td {
            padding: 5px;
            border: 1px solid #399;
        }

    </style>

</head>

<body>

    <table>

        <caption>
            Таблица изменений добычи ресурсов
        </caption>

        <tr>
            <td>Нефть</td>
            <td>43</td>
        </tr>

        <tr>
            <td>Золото</td>
            <td>29</td>
        </tr>

    </table>

</body>
</html>
