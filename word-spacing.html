word-spacing

Задаёт дополнительное расстояние между словами в тексте. Значения могут быть положительными и отрицательными.

Синтаксис

word-spacing: normal | значение | inherit

Значения

normal — стандартные межсловные пробелы (по умолчанию).
значение — дополнительное расстояние (px, em). Отрицательные значения уменьшают расстояние.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>word-spacing</title>
<style>
.wide    { word-spacing: 15px; background: #e8f4f8; padding: 5px; margin: 5px 0; }
.narrow  { word-spacing: -3px; background: #f8e8e8; padding: 5px; margin: 5px 0; }
</style>
</head>
<body>
<p class="wide">Слова с большим расстоянием между ними</p>
<p class="narrow">Слова с уменьшенным расстоянием</p>
</body>
</html>
