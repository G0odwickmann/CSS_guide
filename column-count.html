column-count

Определяет количество колонок, на которые будет разбиваться текст внутри элемента. Свойство удобно использовать для создания газетного или журнального оформления текста.

Синтаксис

column-count: auto | число | inherit
auto
Количество колонок определяется автоматически на основе других свойств.

число
Задает количество колонок, на которые разбивается текст.

inherit
Наследует значение родителя.
Ширина колонок рассчитывается автоматически в зависимости от размеров элемента и количества колонок.

Пример 1:

<!DOCTYPE html>
<html>

<head>

    <meta charset="utf-8">

    <title>column-count</title>

    <style>

        .text {
            column-count: 3;
            column-gap: 30px;
        }

    </style>

</head>

<body>

    <div class="text">

        Много лет назад печатные издания
        использовали колонки для удобства чтения.
        Сегодня CSS позволяет легко создавать
        подобное оформление текста
        на веб-страницах.

    </div>

</body>

</html>
