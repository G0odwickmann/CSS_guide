word-break

Определяет, как должны переноситься слова при достижении края строки. Особенно важно для длинных слов и текстов на языках без пробелов.

Синтаксис

word-break: normal | break-all | keep-all | break-word | inherit

Значения

normal — стандартные правила переноса (по умолчанию).
break-all — перенос в любом месте слова для латиницы и кириллицы.
keep-all — запрет переноса для китайского/японского/корейского.
break-word — перенос только при необходимости.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>word-break</title>
<style>
.box {
    width: 150px;
    border: 1px solid #888;
    padding: 8px;
    margin: 5px 0;
    background: #f9f9f9;
}
.normal    { word-break: normal; }
.break-all { word-break: break-all; }
</style>
</head>
<body>
<div class="box normal">normalLongWordWithoutSpaces будет торчать</div>
<div class="box break-all">break-allLongWordWithoutSpaces переносится</div>
</body>
</html>
