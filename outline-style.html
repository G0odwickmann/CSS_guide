outline-style

Задаёт стиль линии контура элемента. Без этого свойства контур не отображается. Синтаксис аналогичен border-style.

Синтаксис

outline-style: none | dotted | dashed | solid | double | groove | ridge | inset | outset | inherit

Значения

none — контур не отображается (по умолчанию).
dotted — пунктир из точек.
dashed — штриховой пунктир.
solid — сплошная линия.
double — двойная линия.
groove / ridge / inset / outset — трёхмерные стили.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>outline-style</title>
<style>
div {
    outline-width: 3px;
    outline-color: #9b59b6;
    padding: 10px;
    margin: 10px;
    display: inline-block;
}
.solid  { outline-style: solid; }
.dashed { outline-style: dashed; }
.dotted { outline-style: dotted; }
.double { outline-style: double; }
</style>
</head>
<body>
<div class="solid">solid</div>
<div class="dashed">dashed</div>
<div class="dotted">dotted</div>
<div class="double">double</div>
</body>
</html>
