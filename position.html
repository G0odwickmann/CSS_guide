position

Определяет способ позиционирования элемента в документе. От значения этого свойства зависит поведение свойств top, right, bottom и left.

Синтаксис

position: static | relative | absolute | fixed | sticky | inherit

Значения

static — нормальный поток документа (по умолчанию).
relative — смещение относительно нормального положения.
absolute — позиционирование относительно ближайшего предка с position != static.
fixed — позиционирование относительно окна браузера, не прокручивается.
sticky — комбинация relative и fixed в зависимости от прокрутки.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>position</title>
<style>
.relative-box {
    position: relative;
    top: 20px;
    left: 30px;
    background: #aed6f1;
    padding: 10px;
    display: inline-block;
}
.static-box {
    background: #a9dfbf;
    padding: 10px;
    display: inline-block;
}
</style>
</head>
<body>
<div class="static-box">static (обычный поток)</div>
<div class="relative-box">relative: смещён на top:20px, left:30px</div>
</body>
</html>

Пример 2:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>position absolute</title>
<style>
.parent {
    position: relative;
    width: 300px;
    height: 150px;
    background: #fdebd0;
    border: 2px solid #e59866;
}
.child {
    position: absolute;
    bottom: 10px;
    right: 10px;
    background: #e59866;
    color: white;
    padding: 5px 10px;
}
</style>
</head>
<body>
<div class="parent">
    Родитель (relative)
    <div class="child">Дочерний (absolute)</div>
</div>
</body>
</html>
