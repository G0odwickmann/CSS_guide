:optional

Псевдокласс :optional выбирает элементы форм, у которых нет атрибута required, то есть заполнение которых необязательно.

Синтаксис

селектор:optional { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:optional</title>
    <style>
        input:optional {
            border: 1px solid #aaa;
            opacity: 0.8;
        }
        input:required {
            border: 2px solid #E27D60;
        }
    </style>
</head>
<body>
    <form>
        <input type="text" required placeholder="Обязательное поле"><br><br>
        <input type="text" placeholder="Необязательное поле">
    </form>
</body>
</html>
