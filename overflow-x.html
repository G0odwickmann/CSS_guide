overflow-x

Управляет отображением содержимого, выходящего за горизонтальные пределы блока. Аналог overflow, но только для горизонтальной оси.

Синтаксис

overflow-x: visible | hidden | scroll | auto | inherit

Значения

visible — содержимое видно за пределами блока по горизонтали.
hidden — содержимое обрезается горизонтально.
scroll — горизонтальная полоса прокрутки всегда.
auto — горизонтальная прокрутка при необходимости.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>overflow-x</title>
<style>
.box {
    overflow-x: scroll;
    white-space: nowrap;
    width: 200px;
    border: 1px solid #888;
    padding: 5px;
}
</style>
</head>
<body>
<div class="box">Очень длинная строка текста, которая не переносится и требует горизонтальной прокрутки для чтения.</div>
</body>
</html>
