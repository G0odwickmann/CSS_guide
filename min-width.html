min-width

Задаёт минимальную ширину элемента. Элемент не может стать уже указанного значения независимо от ширины окна браузера.

Синтаксис

min-width: значение | проценты | inherit

Значения

0 — минимальная ширина не ограничена (по умолчанию).
значение — минимальная ширина (px, em, % и др.).

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>min-width</title>
<style>
.btn {
    min-width: 150px;
    padding: 10px 20px;
    background: #41B3A3;
    color: white;
    border: none;
    cursor: pointer;
}
</style>
</head>
<body>
<button class="btn">ОК</button>
<button class="btn">Применить настройки</button>
</body>
</html>
