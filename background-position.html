background-position

Задает начальное положение фонового изображения, установленного с помощью свойства background-image.

В CSS3 допустимо указывать несколько значений для каждого фона, перечисляя значения через запятую.

Синтаксис CSS2.1

background-position: [left | center | right | <проценты> | <значение>] || [top | center | bottom | <проценты> | <значение>] | inherit

Синтаксис CSS3

background-position: <позиция> [, <позиция>]*
У свойства background-position два значения: положение по горизонтали и положение по вертикали.

По горизонтали используются: left, center, right.

По вертикали используются: top, center, bottom.

Кроме ключевых слов положение также можно задавать в процентах, пикселах или других единицах измерения.

Если применяются ключевые слова, порядок их следования не имеет значения.

При процентной записи сначала указывается положение по горизонтали, а затем — по вертикали.

Пример 1:

<!DOCTYPE html PUBLIC
"-//W3C//DTD XHTML 1.0 Strict//EN"

"http://www.w3.org/TR/xhtml1/
DTD/xhtml1-strict.dtd">

<html xmlns=
"http://www.w3.org/1999/xhtml">

<head>

<meta http-equiv="Content-Type"
content="text/html;
charset=utf-8" />

<title>background-position</title>

<style type="text/css">

html {

    height: 100%;
}

body {

    background-image:
    url(images/mybg.png);

    background-position:
    right bottom;

    background-repeat:
    no-repeat;
}

</style>

</head>

<body>

<p>...</p>

</body>

</html>

Пример 2:

<!DOCTYPE html>
<html>

<head>

<meta charset="utf-8">

<title>background-position</title>

<style>

body {

    background-image:
    url(images/pattern-left.png),
    url(images/pattern-right.png);

    background-repeat:
    repeat-y, repeat-y;

    background-position:
    left, right;
}

</style>

</head>

<body>

<div style="height:2000px">
</div>

</body>

</html>
Соотношение между ключевыми словами и процентной записью:

top left = 0% 0% — левый верхний угол.

center = 50% 50% — расположение по центру.

right bottom = 100% 100% — правый нижний угол.

В скобках указывается, где располагается фоновый рисунок относительно контейнера.

При inherit значение наследуется от родителя элемента.
