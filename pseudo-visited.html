:visited

Псевдокласс :visited применяется к ссылкам, которые пользователь уже посещал. Из соображений приватности браузеры ограничивают набор CSS-свойств, применимых через :visited.

Синтаксис

a:visited { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:visited</title>
    <style>
        a:link {
            color: #41B3A3;
        }
        a:visited {
            color: #999;
            text-decoration: line-through;
        }
    </style>
</head>
<body>
    <a href="https://example.com">Ссылка на example.com</a><br>
    <a href="">Посещённая страница</a>
</body>
</html>
