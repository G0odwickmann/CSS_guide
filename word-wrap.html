word-wrap

Позволяет переносить длинные слова на новую строку, если они не помещаются в блок. Является псевдонимом для overflow-wrap.

Синтаксис

word-wrap: normal | break-word | inherit

Значения

normal — перенос только в допустимых местах (по умолчанию).
break-word — принудительный перенос длинного слова, чтобы оно не выходило за границы блока.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>word-wrap</title>
<style>
.normal     { word-wrap: normal;     width: 150px; border: 1px solid #888; padding: 8px; margin: 5px 0; background: #fff3cd; }
.break-word { word-wrap: break-word; width: 150px; border: 1px solid #888; padding: 8px; margin: 5px 0; background: #d5f5e3; }
</style>
</head>
<body>
<div class="normal">ОченьДлинноеСловоБезПробелов — выходит за блок</div>
<div class="break-word">ОченьДлинноеСловоБезПробелов — переносится</div>
</body>
</html>
