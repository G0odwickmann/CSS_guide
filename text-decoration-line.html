text-decoration-line

Задаёт тип линии оформления текста: подчёркивание, надчёркивание или зачёркивание. Можно указать несколько значений через пробел.

Синтаксис

text-decoration-line: none | underline | overline | line-through | inherit

Значения

none — линии нет.
underline — подчёркивание.
overline — надчёркивание.
line-through — зачёркивание.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>text-decoration-line</title>
<style>
.combo {
    text-decoration-line: underline overline;
    text-decoration-color: #41B3A3;
}
</style>
</head>
<body>
<p class="combo">Текст одновременно с подчёркиванием и надчёркиванием</p>
</body>
</html>
