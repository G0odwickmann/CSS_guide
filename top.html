top

Для позиционированного элемента задаёт расстояние от верхнего края родительского элемента до верхнего края дочернего. Работает совместно со свойством position.

Синтаксис

top: значение | проценты | auto | inherit

Значения

значение — расстояние в px, em, % и др.
auto — браузер вычисляет положение автоматически.
inherit — наследует значение от родителя.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>top</title>
<style>
.container {
    position: relative;
    height: 150px;
    background: #fef0cd;
    border: 2px solid #f0a500;
}
.box {
    position: absolute;
    top: 30px;
    left: 20px;
    background: #f0a500;
    color: white;
    padding: 8px;
}
</style>
</head>
<body>
<div class="container">
    <div class="box">top: 30px от верхнего края родителя</div>
</div>
</body>
</html>
