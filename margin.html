margin

Устанавливает внешние отступы элемента — пространство между его границей и соседними элементами. Можно задать одно, два, три или четыре значения для разных сторон.

Синтаксис

margin: значение | проценты | auto | inherit margin: верх право низ лево

Значения

auto — браузер вычисляет отступ автоматически (используется для горизонтального центрирования).
значение — числовое значение с единицами измерения (px, em, rem, % и др.).
Одно значение задаёт отступ со всех сторон. Два значения: верх/низ и право/лево. Три: верх, право/лево, низ. Четыре: верх, право, низ, лево.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>margin</title>
<style>
.box {
    background: #AED9E0;
    border: 2px solid #5E9EA0;
    padding: 10px;
    margin: 20px 40px;
    width: 200px;
}
</style>
</head>
<body>
<div class="box">Блок с отступами 20px сверху/снизу и 40px справа/слева</div>
<div class="box">Второй блок</div>
</body>
</html>

Пример 2:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>margin auto</title>
<style>
.centered {
    width: 300px;
    margin: 0 auto;
    background: #FFD700;
    padding: 15px;
    text-align: center;
}
</style>
</head>
<body>
<div class="centered">Блок по центру страницы</div>
</body>
</html>
