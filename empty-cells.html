empty-cells

Задает отображение границ и фона в ячейке, если она пуста. При использовании border-collapse: collapse свойство empty-cells игнорируется.

Ячейка считается пустой, если:
  • в ней нет символов;
  • содержится только пробел или перевод строки;
  • visibility установлено как hidden.
Добавление &nbsp; воспринимается как видимое содержимое.

Синтаксис

empty-cells: show | hide

Значения

Значение Описание
show Отображает границу вокруг ячейки и фон в ней.
hide Граница и фон в пустых ячейках не отображаются.

Пример:

<!DOCTYPE html>
<html>
<head>

<meta charset="utf-8">

<title>empty-cells</title>

<style>

table {

    border: 4px double #399;
}

td {

    background: #fc0;

    border: 1px solid #333;

    empty-cells: hide;

    padding: 5px;
}

</style>

</head>

<body>

<table width="100%">

<tr>
<td>Леонардо</td>
<td>5</td>
<td>8</td>
</tr>

<tr>
<td>Рафаэль</td>
<td> </td>
<td>11</td>
</tr>

<tr>
<td>Микеланджело</td>
<td>24</td>
<td></td>
</tr>

<tr>
<td>Донателло</td>
<td>&nbsp;</td>
<td>13</td>
</tr>

</table>

</body>
</html>
