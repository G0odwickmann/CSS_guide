tab-size

Задаёт ширину символа табуляции в элементах с предварительным форматированием (например, <pre>). Можно указать количество пробелов или конкретную длину.

Синтаксис

tab-size: число | значение | inherit

Значения

число — количество пробелов, которым соответствует символ табуляции (по умолчанию 8).
значение — конкретная ширина в px, em и др.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>tab-size</title>
<style>
pre.tab4 { tab-size: 4; background: #f5f5f5; padding: 10px; }
pre.tab8 { tab-size: 8; background: #e8f5e9; padding: 10px; }
</style>
</head>
<body>
<pre class="tab4">tab-size: 4
	function hello() {
	    return "Hi";
	}</pre>
<pre class="tab8">tab-size: 8
	function hello() {
	    return "Hi";
	}</pre>
</body>
</html>
