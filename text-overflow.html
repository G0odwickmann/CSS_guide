text-overflow

Определяет, как отображается текст, который не помещается в блок. Требует совместного использования с overflow: hidden и white-space: nowrap.

Синтаксис

text-overflow: clip | ellipsis | строка | inherit

Значения

clip — текст просто обрезается (по умолчанию).
ellipsis — вместо обрезанного текста отображается многоточие (…).
строка — произвольный символ вместо обрезанного текста.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>text-overflow</title>
<style>
.clip {
    overflow: hidden;
    white-space: nowrap;
    text-overflow: clip;
    width: 200px;
    background: #e8f4f8;
    padding: 5px;
    margin: 5px 0;
}
.ellipsis {
    overflow: hidden;
    white-space: nowrap;
    text-overflow: ellipsis;
    width: 200px;
    background: #e8f8e8;
    padding: 5px;
    margin: 5px 0;
}
</style>
</head>
<body>
<div class="clip">Очень длинный текст, который не помещается в блок (clip)</div>
<div class="ellipsis">Очень длинный текст, который не помещается в блок (ellipsis)</div>
</body>
</html>
