::first-letter

Псевдоэлемент ::first-letter применяет стили к первой букве первой строки блочного элемента. Часто используется для создания эффекта «буквицы» (dropcap) в типографике.

Синтаксис

селектор::first-letter { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>::first-letter</title>
    <style>
        p::first-letter {
            font-size: 3em;
            font-weight: bold;
            color: #41B3A3;
            float: left;
            line-height: 1;
            margin-right: 5px;
        }
    </style>
</head>
<body>
    <p>Однажды в студёную зимнюю пору я из лесу вышел — был сильный мороз. Гляжу, поднимается медленно в гору лошадка, везущая хворосту воз.</p>
</body>
</html>
