text-shadow

Добавляет тень к тексту. Можно задать несколько теней через запятую. Тени накладываются поверх текста в порядке перечисления.

Синтаксис

text-shadow: сдвиг-x сдвиг-y [размытие] [цвет] [, ...] | none | inherit

Значения

сдвиг-x — горизонтальное смещение тени.
сдвиг-y — вертикальное смещение тени.
размытие — радиус размытия (необязательно).
цвет — цвет тени (необязательно).

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>text-shadow</title>
<style>
h1 {
    text-shadow: 2px 2px 4px rgba(0,0,0,0.4);
    font-size: 36px;
}
h2 {
    text-shadow: 3px 3px 0 #41B3A3, -1px -1px 0 #E27D60;
    font-size: 30px;
}
</style>
</head>
<body>
<h1>Тень с размытием</h1>
<h2>Две тени сразу</h2>
</body>
</html>
