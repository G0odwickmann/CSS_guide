border-color

Устанавливает цвет границы на разных сторонах элемента. Свойство позволяет задать цвет границы сразу для всех сторон элемента или только для указанных.

Синтаксис

border-color: [цвет | transparent] {1,4} | inherit
transparent
Устанавливает прозрачный цвет.
inherit
Наследует значение родителя.

Вы можете выбрать любой цвет указав его в RGB или через хэштег (#), или же воспользоваться стандартными цветами из Visual Studio Code (начав прописывать цвет, например black, white, green и тп.)

Разрешается использовать одно, два, три или четыре значения, разделяя их между собой пробелом. Результат зависит от количества и указан в таблице:
Число значений Результат
1 Цвет границы будет установлен для всех сторон элемента.
2 Первое значение устанавливает цвет верхней и нижней границы, второе — левой и правой.
3 Первое значение задает цвет верхней границы, второе — одновременно левой и правой границы, а третье — нижней границы.
4 Поочередно устанавливается цвет верхней, правой, нижней и левой границы.

Пример:

<html>

<head>

    <meta charset="utf-8">

    <title>border-color</title>

    <style>

        h1 {
            border-color: red white;
            border-style: solid;
        }

        p {
            border-color: #008a77;
            border-style: solid;
            padding: 5px;
        }

    </style>

</head>
