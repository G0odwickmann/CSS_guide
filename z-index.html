z-index

Задаёт порядок наложения позиционированных элементов по оси Z. Элемент с большим z-index отображается поверх элементов с меньшим значением.

Синтаксис

z-index: auto | целое_число | inherit

Значения

auto — элемент имеет тот же порядок наложения, что и родитель (по умолчанию).
целое_число — явный порядок (может быть отрицательным). Работает только для позиционированных элементов (position != static).

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>z-index</title>
<style>
.box {
    position: absolute;
    width: 100px;
    height: 100px;
    text-align: center;
    line-height: 100px;
    font-weight: bold;
}
.box1 { background: rgba(231,76,60,0.8);  z-index: 1; top: 20px; left: 20px; }
.box2 { background: rgba(52,152,219,0.8); z-index: 2; top: 50px; left: 50px; }
.box3 { background: rgba(46,204,113,0.8); z-index: 3; top: 80px; left: 80px; }
</style>
</head>
<body>
<div style="position:relative; height:200px;">
    <div class="box box1">z:1</div>
    <div class="box box2">z:2</div>
    <div class="box box3">z:3</div>
</div>
</body>
</html>

Пример 2:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>z-index модальное окно</title>
<style>
.overlay {
    position: fixed;
    top: 0; left: 0;
    width: 100%; height: 100%;
    background: rgba(0,0,0,0.5);
    z-index: 100;
}
.modal {
    position: fixed;
    top: 50%; left: 50%;
    transform: translate(-50%, -50%);
    background: white;
    padding: 30px;
    z-index: 101;
}
</style>
</head>
<body>
<p>Обычный текст страницы</p>
<div class="overlay"></div>
<div class="modal">Модальное окно поверх всего</div>
</body>
</html>
