max-width

Задаёт максимальную ширину элемента. Элемент не может быть шире указанного значения. Часто используется для адаптивной вёрстки.

Синтаксис

max-width: значение | проценты | none | inherit

Значения

none — максимальная ширина не задана (по умолчанию).
значение — максимальная ширина в px, em, % и др.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>max-width</title>
<style>
.container {
    max-width: 600px;
    margin: 0 auto;
    background: #e8f5e9;
    padding: 20px;
    border: 1px solid #66bb6a;
}
</style>
</head>
<body>
<div class="container">
    Этот блок никогда не превысит 600px в ширину,
    но при необходимости сузится.
</div>
</body>
</html>
