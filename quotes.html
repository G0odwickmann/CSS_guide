quotes

Задаёт символы, используемые в качестве кавычек для псевдоэлементов open-quote и close-quote в свойстве content. Можно задать несколько пар для вложенных цитат.

Синтаксис

quotes: строка строка [строка строка]* | none | inherit

Значения

Значения задаются парами: открывающая и закрывающая кавычка. Дополнительные пары используются для вложенных цитат. none — кавычки не генерируются.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>quotes</title>
<style>
q {
    quotes: "«" "»" "„" """;
}
q::before { content: open-quote; }
q::after  { content: close-quote; }
</style>
</head>
<body>
<p>Он сказал: <q>Это <q>вложенная</q> цитата.</q></p>
</body>
</html>
