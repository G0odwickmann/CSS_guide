font-family

Устанавливает семейство шрифта, которое будет использоваться для оформления текста содержимого.

Список шрифтов может включать одно или несколько названий, разделенных запятой.

Если в имени шрифта содержатся пробелы, название заключается в кавычки.

Когда браузер встречает первый шрифт, он проверяет его наличие на компьютере пользователя.

Синтаксис

font-family: имя_шрифта [, имя_шрифта, ...] | inherit

Значения

Значение Описание
serif Шрифты с засечками, например Times.
sans-serif Рубленые шрифты, например Arial.
cursive Курсивные шрифты.
fantasy Декоративные шрифты.
monospace Моноширинные шрифты.
inherit Наследует значение родителя.

Пример:

<!DOCTYPE html>
<html>

<head>

<meta charset="utf-8">

<title>font-family</title>

<style>

h1 {

    font-family:
    Geneva,
    Arial,
    Helvetica,
    sans-serif;
}

div {

    font-family:
    Georgia,
    "Times New Roman",
    Times,
    serif;
}

</style>

</head>

<body>

<h1>
Duis te feugifacilisi
</h1>

<div>

</div>

</body>
