::after

Псевдоэлемент ::after создаёт виртуальный элемент, который вставляется после содержимого выбранного элемента. Используется вместе со свойством content для добавления декоративного или вспомогательного содержимого без изменения HTML.

Синтаксис

селектор::after { content: '...'; свойство: значение; }

Пример 1:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>::after</title>
    <style>
        .required::after {
            content: ' *';
            color: #E27D60;
            font-weight: bold;
        }
        .clearfix::after {
            content: '';
            display: block;
            clear: both;
        }
    </style>
</head>
<body>
    <label class="required">Имя</label><br>
    <label class="required">Email</label><br>
    <label>Телефон</label>
</body>
</html>

Пример 2:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>::after — кавычки</title>
    <style>
        blockquote::before {
            content: '«';
            font-size: 2em;
            color: #41B3A3;
        }
        blockquote::after {
            content: '»';
            font-size: 2em;
            color: #41B3A3;
        }
    </style>
</head>
<body>
    <blockquote>Красота спасёт мир</blockquote>
</body>
</html>
