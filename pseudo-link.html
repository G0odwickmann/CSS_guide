:link

Псевдокласс :link применяется к ссылкам, которые ещё не были посещены пользователем. Позволяет задать стиль для непосещённых гиперссылок.

Синтаксис

a:link { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:link</title>
    <style>
        a:link {
            color: #41B3A3;
            text-decoration: none;
            font-weight: bold;
        }
        a:visited {
            color: #999;
        }
    </style>
</head>
<body>
    <a href="https://example.com">Непосещённая ссылка</a><br>
    <a href="">Посещённая ссылка</a>
</body>
</html>
