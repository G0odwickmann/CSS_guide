outline-color

Задаёт цвет контура элемента. Свойство используется совместно с outline-style, иначе контур не отображается.

Синтаксис

outline-color: цвет | invert | inherit

Значения

цвет — любое допустимое значение CSS-цвета (название, HEX, rgb, hsl).
invert — инвертирует цвет под контуром для лучшей видимости.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>outline-color</title>
<style>
div {
    outline-style: solid;
    outline-width: 3px;
    outline-color: #e74c3c;
    padding: 10px;
    display: inline-block;
}
</style>
</head>
<body>
<div>Красный контур</div>
</body>
</html>
