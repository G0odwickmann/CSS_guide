page-break-before

Задаёт поведение разрыва страницы перед элементом при печати. Применяется внутри правила @media print.

Синтаксис

page-break-before: auto | always | avoid | left | right | inherit

Значения

auto — разрыв автоматический.
always — всегда вставлять разрыв перед элементом.
avoid — по возможности не делать разрыв.
left / right — начать с левой или правой страницы.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>page-break-before</title>
<style>
@media print {
    h2 {
        page-break-before: always;
    }
}
</style>
</head>
<body>
<p>Вводный текст документа.</p>
<h2>Раздел 1</h2>
<p>При печати перед этим заголовком будет разрыв страницы.</p>
</body>
</html>
