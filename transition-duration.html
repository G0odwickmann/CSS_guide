transition-duration

Задаёт продолжительность анимации перехода. Определяет, за какое время элемент достигнет нового состояния.

Синтаксис

transition-duration: время [, время]* | inherit

Значения

время — длительность в секундах (s) или миллисекундах (ms). По умолчанию 0s — анимация мгновенная.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>transition-duration</title>
<style>
.slow {
    background: #3498db;
    color: white;
    padding: 10px 20px;
    display: inline-block;
    margin: 10px;
    transition-property: background;
    transition-duration: 1.5s;
}
.slow:hover { background: #e74c3c; }
.fast {
    background: #3498db;
    color: white;
    padding: 10px 20px;
    display: inline-block;
    margin: 10px;
    transition-property: background;
    transition-duration: 0.1s;
}
.fast:hover { background: #e74c3c; }
</style>
</head>
<body>
<div class="slow">Медленно (1.5s)</div>
<div class="fast">Быстро (0.1s)</div>
</body>
</html>
