outline-offset

Задаёт расстояние между контуром (outline) и границей элемента. Контур не влияет на поток документа, поэтому отступ может быть и отрицательным.

Синтаксис

outline-offset: значение | inherit

Значения

значение — расстояние в единицах CSS (px, em и др.). Может быть отрицательным.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>outline-offset</title>
<style>
.box {
    outline: 2px solid #41B3A3;
    outline-offset: 8px;
    padding: 15px;
    display: inline-block;
    background: #e0f7fa;
}
</style>
</head>
<body>
<div class="box">Контур с отступом 8px</div>
</body>
</html>
