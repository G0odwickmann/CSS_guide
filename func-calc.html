calc()

CSS-функция calc() позволяет выполнять математические вычисления при задании значений CSS-свойств. Поддерживает операции сложения (+), вычитания (-), умножения (*) и деления (/). Особенно удобна при смешивании единиц измерения (например, px и %).

Синтаксис

свойство: calc(выражение);

Пример 1:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>calc()</title>
    <style>
        .sidebar {
            width: 250px;
            background-color: #41B3A3;
            padding: 10px;
        }
        .main-content {
            width: calc(100% - 270px);
            margin-left: 270px;
            padding: 10px;
            background-color: #e8faf8;
        }
        body { margin: 0; }
        .layout { display: flex; }
    </style>
</head>
<body>
    <div class="layout">
        <div class="sidebar">Боковая панель (250px)</div>
        <div class="main-content">Основное содержимое (100% - 270px)</div>
    </div>
</body>
</html>

Пример 2:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>calc() — шрифт</title>
    <style>
        h1 {
            font-size: calc(1rem + 2vw);
            color: #41B3A3;
        }
        .box {
            width: calc(50% - 20px);
            margin: 10px;
            padding: calc(10px + 1%);
            background-color: #f9d5d5;
            display: inline-block;
        }
    </style>
</head>
<body>
    <h1>Адаптивный заголовок</h1>
    <div class="box">Блок 1</div>
    <div class="box">Блок 2</div>
</body>
</html>
