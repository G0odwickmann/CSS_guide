left

Для позиционированного элемента свойство left определяет расстояние от левого края родительского элемента до левого края дочернего элемента. Отсчёт координат зависит от значения свойства position.

Синтаксис

left: значение | проценты | auto | inherit
Если значение свойства position установлено как absolute, положение элемента определяется относительно окна браузера или родительского элемента с относительным позиционированием.


При значении relative свойство left смещает элемент относительно его исходного положения.


Если родительскому элементу задано position: relative, то дочерний элемент с absolute позиционируется относительно родителя.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>left</title>
<style>

.layer1 {
    position: absolute;
    left: 20px;
    background: #fc3;
    margin: 7px;
}

.layer2 {
    position: relative;
    left: -12px;
    top: 13px;
    border: 1px solid black;
    padding: 5px;
    margin: 7px;
}

</style>
</head>

<body>

<div class="layer1">

    <div class="layer2">

        Lorem ipsum dolor sit amet,
        consectetuer adipiscing elit,
        sed diem nonummy nibh euismod tincidunt.

    </div>

</div>

</body>
</html>

Свойство left может принимать любые единицы длины CSS: пиксели, проценты, пункты и другие значения.

Отрицательные значения left позволяют смещать элемент за пределы исходной позиции.

Значение auto оставляет положение элемента без изменений.

Значение inherit наследует параметр от родительского элемента.

Пример со смещением блока:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>left move</title>
<style>

.box {
    position: relative;
    left: 40px;
    width: 250px;
    padding: 15px;
    background: #FFF1E5;
    border: 3px solid #E27D60;
}

</style>
</head>

<body>

<div class="box">
    Блок смещён вправо
    при помощи свойства left.
</div>

</body>
</html>
