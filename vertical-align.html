vertical-align

Задаёт вертикальное выравнивание строчного элемента или содержимого ячейки таблицы. Не применяется к блочным элементам.

Синтаксис

vertical-align: baseline | top | middle | bottom | text-top | text-bottom | sub | super | значение | проценты | inherit

Значения

baseline — по базовой линии родителя (по умолчанию).
top — по верхнему краю строки.
middle — по середине строки.
bottom — по нижнему краю строки.
sub — как нижний индекс.
super — как верхний индекс.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>vertical-align</title>
<style>
.baseline { vertical-align: baseline; background: #fce4ec; }
.top      { vertical-align: top;      background: #e3f2fd; }
.middle   { vertical-align: middle;   background: #e8f5e9; }
.bottom   { vertical-align: bottom;   background: #fff9c4; }
span { display: inline-block; width: 60px; height: 60px; line-height: 60px; text-align: center; margin: 4px; }
</style>
</head>
<body>
<p>
    Текст
    <span class="baseline">base</span>
    <span class="top">top</span>
    <span class="middle">mid</span>
    <span class="bottom">btm</span>
    текст
</p>
</body>
</html>
