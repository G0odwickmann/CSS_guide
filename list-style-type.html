list-style-type

Устанавливает вид маркера для элементов списка. Применяется к элементам <li>, <ul> и <ol>.

Синтаксис

list-style-type: disc | circle | square | decimal | lower-roman | upper-roman | lower-alpha | upper-alpha | none | inherit

Значения

disc — закрашенный круг.
circle — незакрашенный круг.
square — квадрат.
decimal — арабские цифры.
lower-roman / upper-roman — римские цифры нижнего/верхнего регистра.
lower-alpha / upper-alpha — буквы латинского алфавита.
none — маркеры не отображаются.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>list-style-type</title>
<style>
ul.disc   { list-style-type: disc; }
ul.circle { list-style-type: circle; }
ul.square { list-style-type: square; }
ol.roman  { list-style-type: upper-roman; }
</style>
</head>
<body>
<ul class="disc"><li>disc</li></ul>
<ul class="circle"><li>circle</li></ul>
<ul class="square"><li>square</li></ul>
<ol class="roman"><li>upper-roman</li></ol>
</body>
</html>
