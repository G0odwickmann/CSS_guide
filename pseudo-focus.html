:focus

Псевдокласс :focus применяется к элементу в момент, когда он получает фокус — например, при клике на поле ввода или переходе через клавишу Tab.

Синтаксис

селектор:focus { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:focus</title>
    <style>
        input:focus {
            border: 2px solid #41B3A3;
            outline: none;
            background-color: #e8faf8;
        }
        button:focus {
            box-shadow: 0 0 0 3px rgba(65,179,163,0.4);
        }
    </style>
</head>
<body>
    <input type="text" placeholder="Кликните сюда"><br><br>
    <button>Кнопка</button>
</body>
</html>
