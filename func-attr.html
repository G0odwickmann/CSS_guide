attr()

CSS-функция attr() возвращает значение атрибута выбранного элемента в виде строки. Чаще всего используется вместе с псевдоэлементами ::before и ::after для вывода значений HTML-атрибутов в содержимое.

Синтаксис

content: attr(имя-атрибута);

Пример 1:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>attr()</title>
    <style>
        a::after {
            content: ' (' attr(href) ')';
            font-size: 0.8em;
            color: #41B3A3;
        }
    </style>
</head>
<body>
    <a href="https://example.com">Ссылка на пример</a><br>
    <a href="https://css-tricks.com">CSS-Tricks</a>
</body>
</html>

Пример 2:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>attr() — подсказки</title>
    <style>
        [data-tooltip]::after {
            content: attr(data-tooltip);
            display: block;
            font-size: 0.75em;
            color: #E27D60;
            font-style: italic;
        }
    </style>
</head>
<body>
    <span data-tooltip="Это пояснение к элементу">Наведи внимание</span>
</body>
</html>
