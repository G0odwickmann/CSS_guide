text-decoration

Универсальное свойство для оформления текста: добавляет линии подчёркивания, надчёркивания или зачёркивания. Объединяет text-decoration-line, text-decoration-style и text-decoration-color.

Синтаксис

text-decoration: text-decoration-line text-decoration-style text-decoration-color | none | inherit

Значения

underline — подчёркивание.
overline — надчёркивание.
line-through — зачёркивание.
none — без украшений.
Стили: solid, dashed, dotted, double, wavy.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>text-decoration</title>
<style>
.under  { text-decoration: underline; }
.over   { text-decoration: overline; }
.strike { text-decoration: line-through; }
.wavy   { text-decoration: underline wavy red; }
</style>
</head>
<body>
<p class="under">Подчёркнутый текст</p>
<p class="over">Надчёркнутый текст</p>
<p class="strike">Зачёркнутый текст</p>
<p class="wavy">Волнистое подчёркивание красного цвета</p>
</body>
</html>
