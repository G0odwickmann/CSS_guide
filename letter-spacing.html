letter-spacing

Описание

Определяет интервал между символами в пределах элемента. Браузеры обычно устанавливают расстояние между буквами исходя из типа и вида шрифта, его размеров и настроек операционной системы. Чтобы изменить этот интервал и применяется свойство letter-spacing.

Синтаксис

letter-spacing: normal | значение | inherit

Значения

В качестве значений принимаются любые единицы длины, принятые в CSS — например, пикселы (px), пункты (pt), em и др. Допускается использование отрицательных значений.

normal Нормальное расстояние между символами. Значение по умолчанию.
inherit Наследует значение родителя.

Пример

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>letter-spacing</title>
    <style>

    h1 {
        letter-spacing: -1px;
    }

    p {
        letter-spacing: 0.2em;
    }

    </style>
</head>

<body>

<h1>Заголовок текста</h1>

<p>
Lorem ipsum dolor sit amet,
consectetuer adipiscing elit,
sed diem nonummy nibh euismod tincidunt
ut lacreet dolore magna aliquam erat volutpat.
</p>

</body>
</html>
Положительные значения увеличивают расстояние между буквами, а отрицательные — уменьшают.

Свойство удобно применять для оформления заголовков, декоративного текста и улучшения читаемости.

При использовании больших интервалов текст может занимать больше места по ширине.

Пример:
