:last-of-type

Псевдокласс :last-of-type выбирает последний элемент указанного типа среди дочерних элементов родителя. Аналогичен :first-of-type, но выбирает последний, а не первый.

Синтаксис

селектор:last-of-type { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:last-of-type</title>
    <style>
        p:last-of-type {
            color: #41B3A3;
            font-weight: bold;
            border-bottom: 2px solid #41B3A3;
        }
    </style>
</head>
<body>
    <div>
        <p>Первый параграф</p>
        <p>Второй параграф</p>
        <p>Последний параграф</p>
        <span>Span элемент</span>
    </div>
</body>
</html>
