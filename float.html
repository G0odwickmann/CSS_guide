float

Определяет, по какой стороне будет выравниваться элемент, при этом остальные элементы будут обтекать его с других сторон.

Когда значение свойства float равно none, элемент выводится на странице как обычно.

Синтаксис

float: left | right | none | inherit

Значения

Значение Описание
left Выравнивает элемент по левому краю, а остальные элементы обтекают его справа.
right Выравнивает элемент по правому краю, а остальные элементы обтекают его слева.
none Обтекание элемента не задается.
inherit Наследует значение родителя.

Пример:

<!DOCTYPE html>
<html>

<head>

<meta charset="utf-8">

<title>float</title>

<style>

.layer1 {

    float: left;

    background: #fd0;

    border: 1px solid black;

    padding: 10px;

    margin-right: 20px;

    width: 40%;
}

</style>

</head>

<body>

<div class="layer1">
