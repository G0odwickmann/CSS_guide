page-break-after

Задаёт поведение разрыва страницы после элемента при печати или формировании PDF. Полезно для управления компоновкой печатных документов.

Синтаксис

page-break-after: auto | always | avoid | left | right | inherit

Значения

auto — разрыв автоматический (по умолчанию).
always — всегда вставлять разрыв после элемента.
avoid — по возможности не делать разрыв.
left / right — разрыв так, чтобы следующая страница была левой или правой.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>page-break-after</title>
<style>
@media print {
    .chapter {
        page-break-after: always;
    }
}
</style>
</head>
<body>
<div class="chapter">
    <h2>Глава 1</h2>
    <p>Содержимое первой главы.</p>
</div>
<div class="chapter">
    <h2>Глава 2</h2>
    <p>Содержимое второй главы.</p>
</div>
</body>
</html>
