:first-of-type

Псевдокласс :first-of-type выбирает первый элемент указанного типа среди дочерних элементов своего родителя. В отличие от :first-child, не требует быть первым по порядку — только первым среди своего типа.

Синтаксис

селектор:first-of-type { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:first-of-type</title>
    <style>
        p:first-of-type {
            color: #41B3A3;
            font-weight: bold;
        }
        h2:first-of-type {
            text-decoration: underline;
        }
    </style>
</head>
<body>
    <div>
        <h2>Заголовок 1</h2>
        <p>Первый параграф</p>
        <p>Второй параграф</p>
        <h2>Заголовок 2</h2>
    </div>
</body>
</html>
