min-height

Устанавливает минимальную высоту элемента. Если содержимое занимает больше места, элемент растянется. Если меньше — высота не опустится ниже заданного значения.

Синтаксис

min-height: значение | проценты | inherit

Значения

0 — минимальная высота не ограничена (по умолчанию).
значение — конкретная минимальная высота (px, em, % и др.).

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>min-height</title>
<style>
.block {
    min-height: 120px;
    background: #fff3cd;
    border: 2px solid #ffc107;
    padding: 10px;
    width: 200px;
}
</style>
</head>
<body>
<div class="block">Мало текста, но блок будет не ниже 120px.</div>
</body>
</html>
