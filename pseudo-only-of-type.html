:only-of-type

Псевдокласс :only-of-type выбирает элемент, который является единственным элементом своего типа среди братских узлов.

Синтаксис

селектор:only-of-type { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:only-of-type</title>
    <style>
        span:only-of-type {
            background-color: #e8faf8;
            padding: 3px 6px;
            border-radius: 4px;
        }
    </style>
</head>
<body>
    <div>
        <p>Параграф</p>
        <span>Единственный span</span>
    </div>
    <div>
        <span>Span 1</span>
        <span>Span 2</span>
    </div>
</body>
</html>
