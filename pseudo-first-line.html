::first-line

Псевдоэлемент ::first-line применяет стили к первой строке текста в блочном элементе. Первая строка определяется визуально — в зависимости от ширины контейнера и переносов.

Синтаксис

селектор::first-line { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>::first-line</title>
    <style>
        p::first-line {
            font-weight: bold;
            color: #41B3A3;
            font-variant: small-caps;
        }
    </style>
</head>
<body>
    <p>Первая строка этого параграфа будет выделена особым стилем.
    Остальные строки выглядят как обычно и не получают специального оформления.</p>
</body>
</html>
