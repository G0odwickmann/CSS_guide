:required

Псевдокласс :required применяется к элементам формы, у которых установлен атрибут required — то есть обязательным для заполнения.

Синтаксис

селектор:required { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:required</title>
    <style>
        input:required {
            border-left: 4px solid #E27D60;
            padding-left: 6px;
        }
        input:required::placeholder {
            color: #E27D60;
        }
    </style>
</head>
<body>
    <form>
        <input type="text" required placeholder="Обязательное *"><br><br>
        <input type="text" placeholder="Необязательное"><br><br>
        <button type="submit">Отправить</button>
    </form>
</body>
</html>
