:checked

Псевдокласс :checked применяется к элементам формы типа checkbox, radio или option, которые находятся в выбранном (отмеченном) состоянии.

Синтаксис

селектор:checked { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:checked</title>
    <style>
        input[type="checkbox"]:checked + label {
            color: #41B3A3;
            font-weight: bold;
        }
        input[type="radio"]:checked + label {
            color: #E27D60;
        }
    </style>
</head>
<body>
    <input type="checkbox" id="cb1">
    <label for="cb1">Согласен с условиями</label>
    <br>
    <input type="radio" name="r" id="r1">
    <label for="r1">Вариант A</label>
    <input type="radio" name="r" id="r2">
    <label for="r2">Вариант B</label>
</body>
</html>
