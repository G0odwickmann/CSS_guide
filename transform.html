transform

Применяет к элементу двух- или трёхмерные преобразования: поворот, масштабирование, наклон или перемещение. Не влияет на положение соседних элементов.

Синтаксис

transform: функция(значение) [функция(значение)]* | none | inherit

Значения

translate(x, y) — перемещение.
rotate(угол) — поворот.
scale(x, y) — масштабирование.
skew(x, y) — наклон.
matrix() — матрица преобразований.
none — без преобразований.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>transform</title>
<style>
.box {
    width: 80px;
    height: 80px;
    background: #41B3A3;
    display: inline-block;
    margin: 30px;
    color: white;
    text-align: center;
    line-height: 80px;
}
.rotate  { transform: rotate(30deg); }
.scale   { transform: scale(1.5); }
.skew    { transform: skew(20deg, 10deg); }
</style>
</head>
<body>
<div class="box rotate">rotate</div>
<div class="box scale">scale</div>
<div class="box skew">skew</div>
</body>
</html>
