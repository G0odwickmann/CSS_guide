:nth-last-child()

Псевдокласс :nth-last-child() работает аналогично :nth-child(), но отсчёт ведётся с конца, то есть от последнего дочернего элемента.

Синтаксис

селектор:nth-last-child(n) { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:nth-last-child</title>
    <style>
        li:nth-last-child(1) {
            color: #E27D60;
            font-weight: bold;
        }
        li:nth-last-child(2) {
            color: #41B3A3;
        }
    </style>
</head>
<body>
    <ul>
        <li>Пункт 1</li>
        <li>Пункт 2</li>
        <li>Пункт 3 (предпоследний)</li>
        <li>Пункт 4 (последний)</li>
    </ul>
</body>
</html>
