width

Задаёт ширину элемента. Не включает padding, border и margin, если не задано box-sizing: border-box.

Синтаксис

width: значение | проценты | auto | inherit

Значения

auto — браузер рассчитывает ширину автоматически (по умолчанию).
значение — конкретная ширина (px, em, rem, % и др.).

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>width</title>
<style>
.px-width  { width: 200px; background: #aed6f1; padding: 8px; margin: 5px 0; }
.pct-width { width: 50%;   background: #a9dfbf; padding: 8px; margin: 5px 0; }
</style>
</head>
<body>
<div class="px-width">width: 200px</div>
<div class="pct-width">width: 50%</div>
</body>
</html>
