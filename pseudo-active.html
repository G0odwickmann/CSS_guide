:active

Псевдокласс :active применяется к элементу в момент его активации пользователем — как правило, при нажатии кнопки мыши. Чаще всего используется для ссылок и кнопок.

Синтаксис

селектор:active { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:active</title>
    <style>
        a:active {
            color: #E27D60;
            text-decoration: none;
        }
        button:active {
            background-color: #41B3A3;
            transform: scale(0.97);
        }
    </style>
</head>
<body>
    <a href="#">Нажми на меня</a>
    <br><br>
    <button>Кнопка</button>
</body>
</html>
