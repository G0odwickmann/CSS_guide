:nth-of-type()

Псевдокласс :nth-of-type() выбирает элементы указанного типа по их порядковому номеру среди братских элементов того же типа. Принимает те же аргументы, что и :nth-child().

Синтаксис

селектор:nth-of-type(n) { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:nth-of-type</title>
    <style>
        p:nth-of-type(2) {
            color: #41B3A3;
            font-weight: bold;
        }
        p:nth-of-type(odd) {
            background-color: #f5f5f5;
        }
    </style>
</head>
<body>
    <p>Параграф 1</p>
    <p>Параграф 2</p>
    <p>Параграф 3</p>
    <p>Параграф 4</p>
</body>
</html>
