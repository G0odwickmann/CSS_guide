column-width

Определяет оптимальную ширину колонок в многоколоночном тексте. Браузер автоматически вычисляет количество колонок на основе заданной ширины.

Синтаксис

column-width: auto | длина | inherit
auto
Ширина колонок вычисляется автоматически.

длина
Задает желаемую ширину колонок в единицах CSS, например px, em, rem и др.

inherit
Наследует значение родителя.
Если ширина контейнера не позволяет разместить несколько колонок, браузер автоматически уменьшает их количество.

Пример 1:

<!DOCTYPE html>
<html>

<head>

    <meta charset="utf-8">

    <title>column-width</title>

    <style>

        .text {
            column-width: 200px;
            column-gap: 30px;
        }

    </style>

</head>

<body>

    <div class="text">

        CSS позволяет создавать
        многоколоночные блоки текста.
        Свойство column-width задает
        рекомендуемую ширину колонок,
        а браузер сам определяет
        их итоговое количество.

    </div>

</body>

</html>
