::selection

Псевдоэлемент ::selection применяет стили к части текста, выделенной пользователем с помощью мыши или клавиатуры. Позволяет изменить цвет выделения и фон.

Синтаксис

селектор::selection { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>::selection</title>
    <style>
        ::selection {
            background-color: #41B3A3;
            color: #ffffff;
        }
        .special::selection {
            background-color: #E27D60;
            color: #ffffff;
        }
    </style>
</head>
<body>
    <p>Выделите этот текст мышью, чтобы увидеть кастомный цвет выделения.</p>
    <p class="special">А этот параграф имеет другой цвет выделения.</p>
</body>
</html>
