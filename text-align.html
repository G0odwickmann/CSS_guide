text-align

Устанавливает горизонтальное выравнивание текста внутри блочного элемента.

Синтаксис

text-align: left | right | center | justify | inherit

Значения

left — по левому краю (по умолчанию для LTR).
right — по правому краю.
center — по центру.
justify — по ширине (равномерное распределение пробелов).

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>text-align</title>
<style>
.left    { text-align: left;    background: #e8f4f8; padding: 5px; margin: 4px; }
.center  { text-align: center;  background: #e8f8e8; padding: 5px; margin: 4px; }
.right   { text-align: right;   background: #f8e8e8; padding: 5px; margin: 4px; }
.justify { text-align: justify; background: #f8f4e8; padding: 5px; margin: 4px; }
</style>
</head>
<body>
<div class="left">Выравнивание по левому краю</div>
<div class="center">Выравнивание по центру</div>
<div class="right">Выравнивание по правому краю</div>
<div class="justify">Выравнивание по ширине: текст растягивается равномерно по всей ширине блока для красивого отображения.</div>
</body>
</html>
