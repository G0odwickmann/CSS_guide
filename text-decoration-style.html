text-decoration-style

Задаёт стиль линии оформления текста, заданной свойством text-decoration-line.

Синтаксис

text-decoration-style: solid | double | dotted | dashed | wavy | inherit

Значения

solid — сплошная линия (по умолчанию).
double — двойная линия.
dotted — точечная линия.
dashed — пунктирная линия.
wavy — волнистая линия.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>text-decoration-style</title>
<style>
p { text-decoration-line: underline; margin: 8px 0; }
.solid  { text-decoration-style: solid;  }
.dashed { text-decoration-style: dashed; }
.wavy   { text-decoration-style: wavy;   text-decoration-color: red; }
</style>
</head>
<body>
<p class="solid">solid — сплошная</p>
<p class="dashed">dashed — пунктирная</p>
<p class="wavy">wavy — волнистая</p>
</body>
</html>
