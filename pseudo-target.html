:target

Псевдокласс :target применяется к элементу, являющемуся целью текущей ссылки-якоря (когда URL содержит фрагмент #id, соответствующий данному элементу).

Синтаксис

селектор:target { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:target</title>
    <style>
        section:target {
            background-color: #e8faf8;
            border-left: 4px solid #41B3A3;
            padding: 10px;
        }
    </style>
</head>
<body>
    <nav>
        <a href="#section1">Раздел 1</a> |
        <a href="#section2">Раздел 2</a>
    </nav>
    <section id="section1"><h2>Раздел 1</h2><p>Содержимое раздела 1</p></section>
    <section id="section2"><h2>Раздел 2</h2><p>Содержимое раздела 2</p></section>
</body>
</html>
