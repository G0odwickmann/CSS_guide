:not()

Псевдокласс :not() (отрицание) выбирает элементы, которые не соответствуют указанному селектору. Позволяет исключить определённые элементы из применяемых стилей.

Синтаксис

селектор:not(исключение) { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:not</title>
    <style>
        p:not(.special) {
            color: #666;
        }
        .special {
            color: #E27D60;
            font-weight: bold;
        }
        li:not(:last-child) {
            border-bottom: 1px solid #ddd;
        }
    </style>
</head>
<body>
    <p>Обычный параграф</p>
    <p class="special">Особый параграф</p>
    <p>Ещё обычный</p>
</body>
</html>
