overflow

Управляет отображением содержимого элемента, которое выходит за пределы его блока. Применяется к блочным элементам с заданной высотой.

Синтаксис

overflow: visible | hidden | scroll | auto | inherit

Значения

visible — содержимое выходит за пределы блока (по умолчанию).
hidden — содержимое обрезается и не показывается.
scroll — добавляется полоса прокрутки.
auto — полоса прокрутки добавляется при необходимости.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>overflow</title>
<style>
.hidden { overflow: hidden;  height: 50px; background: #fce4ec; border: 1px solid #e91e63; padding: 5px; margin: 5px; width: 200px; }
.scroll { overflow: scroll;  height: 50px; background: #e8f5e9; border: 1px solid #4caf50; padding: 5px; margin: 5px; width: 200px; }
.auto   { overflow: auto;    height: 50px; background: #e3f2fd; border: 1px solid #2196f3; padding: 5px; margin: 5px; width: 200px; }
</style>
</head>
<body>
<div class="hidden">hidden: текст обрезается и не отображается за пределами блока высотой 50px.</div>
<div class="scroll">scroll: прокрутка всегда. Длинный текст для демонстрации прокрутки.</div>
<div class="auto">auto: прокрутка при необходимости. Длинный текст для демонстрации.</div>
</body>
</html>
