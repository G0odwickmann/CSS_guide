visibility

Управляет видимостью элемента. В отличие от display: none, скрытый элемент сохраняет занятое место в потоке документа.

Синтаксис

visibility: visible | hidden | collapse | inherit

Значения

visible — элемент виден (по умолчанию).
hidden — элемент скрыт, но место остаётся.
collapse — для строк/столбцов таблицы: скрывает без занятия места; для остальных аналогичен hidden.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>visibility</title>
<style>
.visible { visibility: visible; background: #a9dfbf; padding: 10px; margin: 5px; }
.hidden  { visibility: hidden;  background: #f9ebea; padding: 10px; margin: 5px; }
</style>
</head>
<body>
<div class="visible">Этот блок виден</div>
<div class="hidden">Этот блок скрыт (но место занято)</div>
<div class="visible">Этот блок тоже виден</div>
</body>
</html>
