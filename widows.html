widows

Задаёт минимальное количество строк блока, которые должны оставаться в верхней части следующей страницы при печати. Дополняет свойство orphans.

Синтаксис

widows: целое_число | inherit

Значения

целое_число — минимальное количество строк вверху новой страницы (по умолчанию 2).

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>widows</title>
<style>
@media print {
    p {
        widows: 3;
    }
}
</style>
</head>
<body>
<p>
    Длинный параграф текста, который может перейти
    на следующую страницу при печати.
    Свойство widows гарантирует минимум 3 строки
    вверху новой страницы.
</p>
</body>
</html>
