transition-property

Определяет CSS-свойства, для которых будет применяться анимация перехода. Можно перечислить несколько свойств через запятую или использовать all.

Синтаксис

transition-property: none | all | свойство [, свойство]* | inherit

Значения

none — анимация не применяется.
all — анимируются все поддерживаемые свойства.
свойство — конкретное CSS-свойство (background, color, width и т. д.).

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>transition-property</title>
<style>
.card {
    width: 150px;
    height: 80px;
    background: #85c1e9;
    color: #333;
    text-align: center;
    line-height: 80px;
    transition-property: background, transform;
    transition-duration: 0.4s;
}
.card:hover {
    background: #2980b9;
    transform: scale(1.1);
    color: white;
}
</style>
</head>
<body>
<div class="card">Наведи мышь</div>
</body>
</html>
