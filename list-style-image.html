list-style-image

Задаёт изображение в качестве маркера элемента списка. Если изображение недоступно, используется значение свойства list-style-type.

Синтаксис

list-style-image: url(путь_к_изображению) | none | inherit

Значения

url() — адрес файла изображения маркера.
none — изображение не используется, применяется стандартный маркер.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>list-style-image</title>
<style>
ul {
    list-style-image: url('marker.png');
}
</style>
</head>
<body>
<ul>
    <li>Пункт первый</li>
    <li>Пункт второй</li>
    <li>Пункт третий</li>
</ul>
</body>
</html>

Пример 2:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>list-style-image fallback</title>
<style>
ul {
    list-style-image: none;
    list-style-type: disc;
    padding-left: 20px;
}
</style>
</head>
<body>
<ul>
    <li>Без изображения</li>
    <li>Стандартный маркер</li>
</ul>
</body>
</html>
