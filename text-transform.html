text-transform

Управляет регистром символов текста. Позволяет переводить текст в верхний или нижний регистр, а также делать каждое слово с заглавной буквы.

Синтаксис

text-transform: none | uppercase | lowercase | capitalize | inherit

Значения

none — текст без изменений (по умолчанию).
uppercase — все буквы заглавные.
lowercase — все буквы строчные.
capitalize — каждое слово начинается с заглавной буквы.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>text-transform</title>
<style>
.upper { text-transform: uppercase; }
.lower { text-transform: lowercase; }
.cap   { text-transform: capitalize; }
</style>
</head>
<body>
<p class="upper">все буквы заглавные</p>
<p class="lower">ВСЕ БУКВЫ СТРОЧНЫЕ</p>
<p class="cap">каждое слово с большой буквы</p>
</body>
</html>
