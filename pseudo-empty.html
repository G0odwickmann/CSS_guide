:empty

Псевдокласс :empty выбирает элементы, которые не содержат никаких дочерних узлов — ни текста, ни других элементов (включая пробелы).

Синтаксис

селектор:empty { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:empty</title>
    <style>
        td:empty {
            background-color: #f9d5d5;
        }
        p:empty {
            display: none;
        }
    </style>
</head>
<body>
    <table border="1">
        <tr>
            <td>Данные</td>
            <td></td>
            <td>Данные</td>
        </tr>
    </table>
    <p>Видимый параграф</p>
    <p></p>
</body>
</html>
