unicode-bidi

Используется совместно со свойством direction для управления двунаправленным текстом (BiDi). Определяет, как браузер обрабатывает встроенные блоки с разными направлениями текста.

Синтаксис

unicode-bidi: normal | embed | bidi-override | isolate | isolate-override | plaintext | inherit

Значения

normal — не добавляет дополнительных уровней двунаправленности (по умолчанию).
embed — открывает дополнительный уровень двунаправленности.
bidi-override — переопределяет алгоритм Unicode BiDi.
isolate — изолирует содержимое от окружающего направления.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>unicode-bidi</title>
<style>
.rtl-block {
    direction: rtl;
    unicode-bidi: embed;
    background: #f0f4ff;
    padding: 10px;
    margin: 5px 0;
    border: 1px solid #8899dd;
}
</style>
</head>
<body>
<p>Обычный текст слева направо.</p>
<div class="rtl-block">نص عربي — текст справа налево</div>
</body>
</html>
