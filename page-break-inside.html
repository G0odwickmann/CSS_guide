page-break-inside

Управляет разрывом страницы внутри элемента при печати. Позволяет запретить разбивку блока на разные страницы.

Синтаксис

page-break-inside: auto | avoid | inherit

Значения

auto — разрывы внутри элемента разрешены (по умолчанию).
avoid — по возможности не разрывать элемент между страницами.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>page-break-inside</title>
<style>
@media print {
    .no-break {
        page-break-inside: avoid;
    }
}
</style>
</head>
<body>
<div class="no-break">
    <h3>Таблица данных</h3>
    <table border="1">
        <tr><td>Строка 1</td></tr>
        <tr><td>Строка 2</td></tr>
    </table>
</div>
</body>
</html>
