table-layout

Определяет алгоритм расчёта ширины столбцов таблицы. Влияет на скорость отрисовки таблицы и способ распределения ширины.

Синтаксис

table-layout: auto | fixed | inherit

Значения

auto — ширина столбцов определяется автоматически по содержимому (по умолчанию).
fixed — ширина столбцов задаётся первой строкой или атрибутом width, что ускоряет отрисовку.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>table-layout</title>
<style>
.fixed-table {
    table-layout: fixed;
    width: 300px;
    border-collapse: collapse;
}
.fixed-table td {
    border: 1px solid #888;
    padding: 8px;
    overflow: hidden;
    text-overflow: ellipsis;
    white-space: nowrap;
}
</style>
</head>
<body>
<table class="fixed-table">
    <tr>
        <td>Короткий</td>
        <td>Очень длинный текст в ячейке таблицы</td>
    </tr>
</table>
</body>
</html>
