:nth-child()

Псевдокласс :nth-child() выбирает дочерние элементы по их порядковому номеру. Принимает аргумент в виде числа, ключевых слов odd/even или формулы an+b.

Синтаксис

селектор:nth-child(n) { свойство: значение; }
odd
Выбирает нечётные дочерние элементы (1-й, 3-й, 5-й…).

even
Выбирает чётные дочерние элементы (2-й, 4-й, 6-й…).

an+b
Формула: a — шаг, b — смещение. Например, 2n+1 = odd, 3n = каждый третий.

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:nth-child</title>
    <style>
        tr:nth-child(even) {
            background-color: #e8faf8;
        }
        li:nth-child(3n) {
            color: #E27D60;
            font-weight: bold;
        }
    </style>
</head>
<body>
    <table border="1">
        <tr><td>Строка 1</td></tr>
        <tr><td>Строка 2</td></tr>
        <tr><td>Строка 3</td></tr>
        <tr><td>Строка 4</td></tr>
    </table>
</body>
</html>
