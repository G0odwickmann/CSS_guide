padding

Задаёт внутренние отступы элемента — расстояние между содержимым и границей блока. Можно указать одно, два, три или четыре значения.

Синтаксис

padding: значение | проценты | inherit padding: верх право низ лево

Значения

Одно значение задаёт отступ со всех сторон. Два значения: верх/низ и право/лево. Три: верх, право/лево, низ. Четыре: верх, право, низ, лево (по часовой стрелке).

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>padding</title>
<style>
.box {
    background: #d5f5e3;
    border: 2px solid #27ae60;
    padding: 20px 40px;
    width: 200px;
}
</style>
</head>
<body>
<div class="box">
    Внутренний отступ: 20px сверху/снизу, 40px справа/слева.
</div>
</body>
</html>

Пример 2:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>padding четыре значения</title>
<style>
.card {
    background: #fef9e7;
    border: 1px solid #f1c40f;
    padding: 10px 20px 30px 15px;
}
</style>
</head>
<body>
<div class="card">Четыре разных отступа: сверху 10px, справа 20px, снизу 30px, слева 15px.</div>
</body>
</html>
