transition-delay

Задаёт задержку перед началом анимации перехода. Позволяет синхронизировать несколько анимаций или начинать переход через определённое время после события.

Синтаксис

transition-delay: время [, время]* | inherit

Значения

время — задержка в секундах (s) или миллисекундах (ms). По умолчанию 0s. Отрицательные значения запускают переход с середины.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>transition-delay</title>
<style>
.box {
    width: 100px;
    height: 100px;
    background: #e27d60;
    transition-property: background;
    transition-duration: 0.5s;
    transition-delay: 0.3s;
}
.box:hover {
    background: #41B3A3;
}
</style>
</head>
<body>
<div class="box"></div>
<p>Наведи курсор — цвет изменится через 0.3s задержки</p>
</body>
</html>
