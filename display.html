display

Многоцелевое свойство, которое определяет, как элемент должен быть показан в документе.

Синтаксис

display: block | inline | inline-block | inline-table | list-item | none | run-in | table | table-caption | table-cell | table-column-group | table-column | table-footer-group | table-header-group | table-row | table-row-group
Список возможных значений свойства display достаточно большой. Наиболее популярные значения: block, inline, inline-block, list-item и none.

Значения свойства

Значение Описание
block Элемент показывается как блочный.
inline Элемент отображается как встроенный.
inline-block Генерирует блочный элемент, который обтекается другими элементами.
inline-table Определяет, что элемент является встроенной таблицей.
list-item Элемент выводится как блочный и добавляется маркер списка.
none Временно удаляет элемент из документа.
run-in Устанавливает элемент как блочный или встроенный в зависимости от контекста.
table Определяет, что элемент является таблицей.
table-caption Задает заголовок таблицы.
table-cell Указывает, что элемент представляет собой ячейку таблицы.
table-column Назначает элемент колонкой таблицы.
table-column-group Определяет группу одной или более колонок таблицы.
table-footer-group Используется для хранения строк ячеек внизу таблицы.
table-header-group Используется для хранения строк ячеек сверху таблицы.
table-row Элемент отображается как строка таблицы.
table-row-group Создает структурный блок из нескольких строк таблицы.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>display</title>

<style>

.example {

    border: dashed 1px #634f36;
    background: #fffff5;

    font-family:
    "Courier New",
    Courier,
    monospace;

    padding: 7px;
    margin: 0 0 1em;
}

.exampleTitle {

    border: 1px solid black;

    border-bottom: none;

    padding: 3px;

    display: inline;

    background: #efecdf;

    font-weight: bold;

    font-size: 90%;

    margin: 0;

    white-space: nowrap;
}

</style>
</head>

<body>

<div class="exampleTitle">
Пример
</div>

<div class="example">

<b>
Формула серной кислоты:
</b>

<i>
H<sub>2</sub>
SO<sub>4</sub>
</i>

</div>

</body>
</html>
