transition-timing-function

Определяет кривую скорости анимации перехода — насколько быстро или медленно переход происходит в разные моменты.

Синтаксис

transition-timing-function: ease | linear | ease-in | ease-out | ease-in-out | cubic-bezier(n,n,n,n) | steps(n) | inherit

Значения

ease — медленно начало, быстро середина, медленный конец (по умолчанию).
linear — постоянная скорость.
ease-in — медленное начало.
ease-out — медленный конец.
ease-in-out — медленное начало и конец.
cubic-bezier() — произвольная кривая Безье.
steps(n) — пошаговая анимация.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>transition-timing-function</title>
<style>
.bar {
    height: 40px;
    width: 60px;
    background: #41B3A3;
    color: white;
    line-height: 40px;
    text-align: center;
    font-size: 12px;
    transition-property: width;
    transition-duration: 1s;
    margin: 6px 0;
}
.bar:hover { width: 300px; }
.ease      { transition-timing-function: ease; }
.linear    { transition-timing-function: linear; }
.ease-in   { transition-timing-function: ease-in; }
.ease-out  { transition-timing-function: ease-out; }
</style>
</head>
<body>
<div class="bar ease">ease</div>
<div class="bar linear">linear</div>
<div class="bar ease-in">ease-in</div>
<div class="bar ease-out">ease-out</div>
<p>Наведи на каждый блок для сравнения скоростей</p>
</body>
</html>
