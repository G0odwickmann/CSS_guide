column-gap

Устанавливает расстояние между колонками внутри многоколоночного текста. Свойство применяется совместно с column-count или column-width.

Синтаксис

column-gap: normal | длина | inherit
normal
Устанавливает расстояние между колонками по умолчанию.

длина
Задает фиксированное расстояние между колонками в единицах CSS, например px, em и др.

inherit
Наследует значение родителя.
Чем больше значение column-gap, тем шире будет промежуток между колонками текста.

Пример 1:

<!DOCTYPE html>
<html>

<head>

    <meta charset="utf-8">

    <title>border-style</title>

    <style>

        div {
            display: inline-block;

            padding: 6px 12px;
            margin: 4px;

            border-width: 3px;
            border-color: #3b5d87;

            font-family: Arial;
        }

        .dotted {
            border-style: dotted;
        }

        .dashed {
            border-style: dashed;
        }

        .solid {
            border-style: solid;
        }

        .double {
            border-style: double;
        }

        .groove {
            border-style: groove;
        }

        .ridge {
            border-style: ridge;
        }

        .inset {
            border-style: inset;
        }

        .outset {
            border-style: outset;
        }

    </style>

</head>

<body>

    <div class="dotted">dotted</div>

    <div class="dashed">dashed</div>

    <div class="solid">solid</div>

    <div class="double">double</div>

    <div class="groove">groove</div>

    <div class="ridge">ridge</div>

    <div class="inset">inset</div>

    <div class="outset">outset</div>

</body>
</html>

Пример 2:

<!DOCTYPE html>
<html>

<head>

    <meta charset="utf-8">

    <title>column-gap</title>

    <style>

        .block {
            column-count: 2;
            column-gap: 80px;
            column-rule: 1px solid #999;
        }

    </style>

</head>

<body>

    <div class="block">

        Увеличенное расстояние между колонками
        делает текст визуально более разделенным
        и улучшает восприятие контента.

    </div>

</body>

</html>
