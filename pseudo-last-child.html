:last-child

Псевдокласс :last-child выбирает элемент, который является последним дочерним элементом своего родителя.

Синтаксис

селектор:last-child { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:last-child</title>
    <style>
        li:last-child {
            color: #E27D60;
            font-weight: bold;
        }
        tr:last-child {
            background-color: #e8faf8;
        }
    </style>
</head>
<body>
    <ul>
        <li>Первый</li>
        <li>Второй</li>
        <li>Последний</li>
    </ul>
</body>
</html>
