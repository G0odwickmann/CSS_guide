list-style

Универсальное свойство, которое позволяет одновременно задать стиль маркера списка, его позицию и изображение. Применяется к элементам <ul> и <ol>.

Синтаксис

list-style: list-style-type list-style-position list-style-image | inherit

Значения

none — убирает маркеры.
disc — закрашенный круг (по умолчанию для <ul>).
circle — незакрашенный круг.
square — квадрат.
decimal — числа (по умолчанию для <ol>).
inside / outside — позиция маркера.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>list-style</title>
<style>
ul.square {
    list-style: square inside;
}
ol.roman {
    list-style: upper-roman outside;
}
</style>
</head>
<body>
<ul class="square">
    <li>Яблоко</li>
    <li>Груша</li>
    <li>Апельсин</li>
</ul>
<ol class="roman">
    <li>Первый</li>
    <li>Второй</li>
    <li>Третий</li>
</ol>
</body>
</html>

Пример 2:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>list-style none</title>
<style>
nav ul {
    list-style: none;
    padding: 0;
    margin: 0;
}
nav ul li {
    display: inline-block;
    margin-right: 10px;
}
</style>
</head>
<body>
<nav>
    <ul>
        <li>Главная</li>
        <li>О нас</li>
        <li>Контакты</li>
    </ul>
</nav>
</body>
</html>
