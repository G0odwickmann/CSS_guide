column-rule

Устанавливает параметры линии, которая отображается между колонками в многоколоночном тексте. Свойство является сокращённой записью для column-rule-width, column-rule-style и column-rule-color.

Синтаксис

column-rule: column-rule-width || column-rule-style || column-rule-color
column-rule-width
Определяет толщину линии между колонками.

column-rule-style
Задает стиль линии: solid, dashed, dotted, double и другие.

column-rule-color
Устанавливает цвет линии между колонками.
Линия отображается строго посередине между колонками и не влияет на ширину текста.

Пример 1:

<!DOCTYPE html>
<html>

<head>

    <meta charset="utf-8">

    <title>column-rule</title>

    <style>

        .text {
            column-count: 3;
            column-gap: 30px;

            column-rule:
            3px solid #41B3A3;
        }

    </style>

</head>

<body>

    <div class="text">

        Многоколоночный текст можно
        дополнительно разделять линиями,
        чтобы визуально отделять
        одну колонку от другой.

    </div>

</body>

</html>

    <title>column-rule</title>

            column-count: 2;
            column-gap: 40px;

            5px dashed orange;
        }

<body>

    <div class="block">

        Свойство column-rule
        позволяет создавать

    </div>
