list-style-position

Определяет, как маркер списка располагается относительно содержимого элемента <li> — внутри блока или снаружи.

Синтаксис

list-style-position: inside | outside | inherit

Значения

outside — маркер находится за пределами блока содержимого (по умолчанию).
inside — маркер является частью блока содержимого, текст обтекает его.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>list-style-position</title>
<style>
.outside {
    list-style-position: outside;
    background: #e8f4f8;
    padding: 10px 30px;
}
.inside {
    list-style-position: inside;
    background: #f4e8f8;
    padding: 10px;
}
</style>
</head>
<body>
<p>outside:</p>
<ul class="outside">
    <li>Длинный текст пункта списка для демонстрации переноса</li>
</ul>
<p>inside:</p>
<ul class="inside">
    <li>Длинный текст пункта списка для демонстрации переноса</li>
</ul>
</body>
</html>
