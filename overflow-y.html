overflow-y

Управляет отображением содержимого, выходящего за вертикальные пределы блока. Аналог overflow, но только для вертикальной оси.

Синтаксис

overflow-y: visible | hidden | scroll | auto | inherit

Значения

visible — содержимое видно за пределами блока по вертикали.
hidden — содержимое обрезается снизу.
scroll — вертикальная полоса прокрутки всегда.
auto — вертикальная прокрутка при необходимости.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>overflow-y</title>
<style>
.box {
    overflow-y: auto;
    height: 80px;
    width: 250px;
    border: 1px solid #888;
    padding: 5px;
}
</style>
</head>
<body>
<div class="box">
    Строка 1<br>Строка 2<br>Строка 3<br>
    Строка 4<br>Строка 5<br>Строка 6<br>
</div>
</body>
</html>
