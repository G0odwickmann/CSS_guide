text-indent

Задаёт величину отступа первой строки текста в блочном элементе. Принимает положительные и отрицательные значения.

Синтаксис

text-indent: значение | проценты | inherit

Значения

значение — числовое значение (px, em, % и др.). Положительное — отступ вправо, отрицательное — выступ влево.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>text-indent</title>
<style>
p {
    text-indent: 2em;
    width: 300px;
    background: #f9f9f9;
    border-left: 3px solid #41B3A3;
    padding: 10px;
}
</style>
</head>
<body>
<p>Это абзац с отступом первой строки в 2em. Остальные строки начинаются у левого края блока.</p>
</body>
</html>
