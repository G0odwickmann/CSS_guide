padding-top

Задаёт верхний внутренний отступ элемента — расстояние между содержимым и верхней границей блока.

Синтаксис

padding-top: значение | проценты | inherit

Значения

значение — числовое значение с единицами измерения (px, em, % и др.).

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>padding-top</title>
<style>
h1 {
    background: #fce4ec;
    padding-top: 25px;
    padding-left: 10px;
    border: 1px solid #f06292;
}
</style>
</head>
<body>
<h1>Заголовок с верхним внутренним отступом 25px</h1>
</body>
</html>
