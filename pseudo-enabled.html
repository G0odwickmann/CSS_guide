:enabled

Псевдокласс :enabled применяется к элементам формы, которые доступны для взаимодействия — то есть не имеют атрибута disabled. Является противоположностью :disabled.

Синтаксис

селектор:enabled { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:enabled</title>
    <style>
        input:enabled {
            border: 2px solid #41B3A3;
            padding: 4px;
        }
        input:disabled {
            border: 2px solid #ccc;
        }
    </style>
</head>
<body>
    <input type="text" placeholder="Доступное поле"><br><br>
    <input type="text" placeholder="Недоступное поле" disabled>
</body>
</html>
