:invalid

Псевдокласс :invalid применяется к элементам формы, значение которых не проходит проверку встроенной валидации HTML5 (например, неверный формат email, пустое обязательное поле).

Синтаксис

селектор:invalid { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:invalid</title>
    <style>
        input:invalid {
            border: 2px solid #E27D60;
            background-color: #fde8e3;
        }
        input:valid {
            border: 2px solid #41B3A3;
        }
    </style>
</head>
<body>
    <input type="email" placeholder="Введите email" value="неверный"><br><br>
    <input type="email" placeholder="Введите email" value="user@mail.ru">
</body>
</html>
