opacity

Задаёт прозрачность элемента. Значение 0 означает полную прозрачность, 1 — полную непрозрачность. Свойство влияет на сам элемент и на всё его содержимое.

Синтаксис

opacity: число (от 0 до 1) | inherit

Значения

0 — элемент полностью прозрачен.
1 — элемент полностью непрозрачен (по умолчанию).
0.5 — элемент полупрозрачен.

Пример:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>opacity</title>
<style>
.box1 { opacity: 1;   background: #e74c3c; padding: 10px; margin: 5px; }
.box2 { opacity: 0.6; background: #e74c3c; padding: 10px; margin: 5px; }
.box3 { opacity: 0.2; background: #e74c3c; padding: 10px; margin: 5px; }
</style>
</head>
<body>
<div class="box1">opacity: 1</div>
<div class="box2">opacity: 0.6</div>
<div class="box3">opacity: 0.2</div>
</body>
</html>

Пример 2:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>opacity hover</title>
<style>
img {
    opacity: 0.5;
    transition: opacity 0.3s;
}
img:hover {
    opacity: 1;
}
</style>
</head>
<body>
<img src="img/img1.png" alt="Пример" width="200">
</body>
</html>
