:valid

Псевдокласс :valid применяется к элементам формы, значение которых успешно прошло встроенную проверку HTML5. Является противоположностью :invalid.

Синтаксис

селектор:valid { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:valid</title>
    <style>
        input:valid {
            border: 2px solid #41B3A3;
            background-color: #e8faf8;
        }
        input:invalid {
            border: 2px solid #E27D60;
        }
    </style>
</head>
<body>
    <input type="email" placeholder="Введите email" value="user@mail.ru"><br><br>
    <input type="email" placeholder="Введите email" value="неверный">
</body>
</html>
