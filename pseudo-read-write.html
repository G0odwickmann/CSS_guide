:read-write

Псевдокласс :read-write выбирает элементы, доступные для редактирования пользователем — редактируемые поля ввода, а также элементы с атрибутом contenteditable.

Синтаксис

селектор:read-write { свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>:read-write</title>
    <style>
        input:read-write {
            border: 2px solid #41B3A3;
            padding: 4px;
        }
        [contenteditable]:read-write {
            border: 2px dashed #41B3A3;
            padding: 5px;
        }
    </style>
</head>
<body>
    <input type="text" placeholder="Редактируемое поле"><br><br>
    <div contenteditable="true">Редактируемый блок</div>
</body>
</html>
