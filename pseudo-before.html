::before

Псевдоэлемент ::before создаёт виртуальный элемент, который вставляется перед содержимым выбранного элемента. Используется вместе со свойством content для добавления декоративных элементов, иконок, счётчиков.

Синтаксис

селектор::before { content: '...'; свойство: значение; }

Пример:

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>::before</title>
    <style>
        h2::before {
            content: '# ';
            color: #41B3A3;
            font-weight: bold;
        }
        .tip::before {
            content: 'ℹ ';
            color: #E27D60;
            font-size: 1.2em;
        }
    </style>
</head>
<body>
    <h2>Раздел CSS</h2>
    <p class="tip">Используйте ::before для декоративных элементов</p>
</body>
</html>
